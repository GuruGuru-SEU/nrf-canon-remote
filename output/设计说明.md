# 遥控器机械改型 v0.10

本版机身 **78 × 43 × 17.35 mm**（不含按键突出），相比原始 140 mm 缩短 62 mm。保留四向圆环、中心键、下方三个圆键，共五个键帽、八个开关；三个长条键和底部五个矩形键全部删除。中心开关改为 **K2-1831SL-A4SW-01**，其余七个为 **TS-1101-C-W**。本版按 Chrome 中当前 PCB 的界面显示角度，将中心两段开关设为 **180°**。

打开 [preview.html](preview.html) 可离线预览。提供“中心两段键”特写、“中心剖切”及“松开 / 半按 / 全按”控制。动作表示几何行程；不表示已实现对焦、快门或 BR-E1 协议。

## 模型来源与边界

原始文件为 `reference/enclosure/shell_top.3mf`、`shell_bottom.3mf`、`buttons_blank.3mf`，板框参考 `reference/pcb/GerberFiles/profile.gbr`。

本版上下壳按参考的宽度、厚度、圆角和正面倒角风格重新建立，安装结构采用上中、下左右三组配套螺柱。不是直接沿用原壳全部内结构。圆环、中心、三个圆键保留原始键帽形状，只做刚性平移并增加相应顶柱；没有将圆形沿单轴压缩。原型对照展示未缩放的原始 140 mm 外壳、全部原始键帽及 Gerber 板框。

PCB 仅做机械外形、孔及 USB 焊盘配合展示，不包含原理图、铜层布线或完整封装设计。USB-C、七个 TS-1101-C-W 与 RGB 的预览使用嘉立创原始下载网格，来源、UUID、SHA-256、坐标转换及限制见 [器件模型记录](../reference/component-models/README.md)。当前 HX TYPE-C 6P QTWT 按 EasyEDA 中 J100 的底面安装状态翻到 PCB 下方，库模型使用底面镜像并保留其开口朝机身尾端的 XY 基准；焊脚面与十个 PCB 焊盘逐一检查。顶部外壳不切 USB 开口；下盖保留端口贯穿孔、11 × 5.1 mm 外侧浅让位及 12.4 mm 耳位让位。USB 端两侧恢复参考外壳的上盖楔形卡扣和下盖凹槽，扣槽名义间隙 0.15 mm、与 PCB 边缘间隙 0.25 mm。U600 为底部声孔麦克风，下盖新增 Ø1.2 mm 声孔与 Ø2.2 mm 内侧 relief。中心 K2-1831SL-A4SW-01 仍按厂家图纸建模；主控和电池为包络。STL/3MF 为网格实体，没有原生 CAD 特征树或 STEP 曲面。

## 顶角四分之一圆凹口与下盖配合

PCB 主体两侧为直边。左上、右上角以 (±18.3787,35.8787) 为圆心，各切除一个 **R5 的四分之一圆**，属于凹形让位。底角保留 R1。板框宽度 36.7574、板顶 Y=35.8787，包含 USB 板舌后的总长为 73.4287 mm。

参考工程下盖有与 PCB 圆弧让位配合的圆形凸台。本版将这种配合方式移至两个上角，重新设计定位台并与下盖侧壁、底板合为一体，参考截面见 [原工程板框与下盖](review/reference-pcb-retention.png)。

| 顶角配合 | 当前参数 |
| --- | --- |
| 凹口圆心 | (-18.3787,35.8787)、(18.3787,35.8787) |
| PCB 凹口 | R5.00，圆弧角度 90° |
| 下盖定位凸台 | R4.75，与凹口同心；名义径向间隙 0.25 |
| 导入斜面 | 从 PCB 顶面 Z=-7.45 到 -7.05，高 0.40、径向缩小 0.40 |
| 下方托台 | R5.60，伸到 PCB 下方；顶面 Z=-9.20，距 PCB 下表面 0.15 |
| 上下盖配合 | 定位凸台最高 -7.05，低于上盖配合唇底部 -6.50 |
| 螺丝固定 | 上中 (0,28)、下左右 (±14,-27)，PCB 孔 Ø2.30 |

凸台外侧裁到原有壳体包络内，保持梯形外形。角部凸台负责定位、托台预留支撑间隙；螺丝固定仍由三组贯穿 PCB 的安装柱承担。0.25 / 0.15 mm 是建模名义间隙，实际打印和 PCB 外形加工公差需样件核对。

RGB、上盖透光孔、导光柱及遮光筒保持 v0.7 的坐标 **(-11.43,29)**（相较 v0.6 下移 5 mm）。LED 位于有效板面内；导光件与两侧定位台、按键均已做干涉检查。

下盖继续采用参考工程的梯形截面：外侧从 Z=-11.35 开始斜收，到 Z=-17.35 时左右各内收 4.00，宽度由 43 变为 35 mm。内壁从 Z=-11.7367、X=±19.8 收到内底面 Z=-16.15、X=±16.8578，底板厚 1.20 mm。两下方沉孔到背面侧边的名义边距为 1.40 mm。

预览中的“PCB 板形”展示两个凹形顶角；“角部配合”展示 PCB、下盖与 LED。该视图下取消“PCB 与 USB 板舌”图层，可查看下盖定位凸台和托台。

## 中心两段式开关

依据韩荣官网提供的 **K2-1831SL-A4SW-□□** 图纸（尾号为序列号）建立 A4SW-01 机械模型。图纸保存在 [k2-1831sl-datasheet.pdf](review/k2-1831sl-datasheet.pdf)，可查看 [尺寸图](review/k2-1831sl-drawing.png)。未用相近的 SF 系列或 A4SA 型替代尺寸。

| 项目 | 厂家尺寸 / 当前适配 |
| --- | --- |
| 主体 | 6.20 × 6.50 × 2.00 |
| 最高点 | 距 PCB 上表面 3.80（主体 2.00 + 操作柱 1.80） |
| 操作柱 | Ø2.50 |
| 四端子 | 外侧总跨度 8.40；两排间距 4.50；端子宽 0.70 |
| 定位柱 | 两根 Ø1.00，伸入板内 0.80；相对开关中心 (-1,±1.75) |
| PCB 定位孔 | 两个 Ø1.10，绝对坐标 (-1,7.25)、(-1,10.75) |
| 第一段 / 第二段累计行程 | 0.30 / 0.55；第二段不是额外再下压 0.55 |
| 中心键顶柱 | Ø2.10；底端 Z=-3.50，比普通键顶柱缩短 1.30 |
| 静态间隙 | 开关顶面 -3.65 至键帽顶柱底端 -3.50：0.15 |
| 半按 / 全按键帽总位移 | 0.45 / 0.70，包含 0.15 空程 |

中心键源外观保持不变。开关壳体中预留操作柱运动腔，仅用于几何示意，不复刻内部弹片。预览中键帽与开关操作柱分别按总位移和实际开关行程移动。几何检查覆盖中心键 0–0.70 mm 内 15 个位置，检查上盖、圆环、PCB、开关壳体及运动操作柱的接触关系。

普通七个开关使用 C318938 原始库模型，整体包络约 8.007 × 3.70 × 2.498（含焊脚）；名义总高 2.50。普通键顶柱底面 -4.80，与下载模型最高点的间隙约 0.152。普通键按 0.15 空程 + 0.25 行程进行轴向下压检查。圆环实际倾斜、材料弹性、回弹和两段手感仍需打印试装；0.15 是名义值，不是已完成公差叠加后的保证值。

## 导出与检查结果

- [完整装配 3MF](models/remote_assembly.3mf)：含电子器件占位，不应整件打印。
- [打印件 3MF](models/printable_parts.3mf)：上盖、下盖、五个键帽、导光件，共八件。
- [中心两段键 STL](models/key_center.stl)、[上盖](models/shell_top.stl)、[下盖](models/shell_bottom.stl)、[PCB](models/pcb.stl)。
- [PCB DXF](models/pcb_outline.dxf) / [SVG](models/pcb_outline.svg)：一个外轮廓、三个固定孔、两个开关定位孔。

STL/3MF 保留统一装配坐标，单位 mm；切片前分别选择方向并落到热床。`models` 已移除不再使用的矩形键与长条键导出，避免误用旧版。

[几何报告](review/geometry-checks.json) 检查 29 个部件的碰撞实体，对 59 组包络重叠候选做布尔求交，目前无外部装配穿透。USB/普通开关先将各自库模型的内部实体合并，RGB 的非封闭库网格以保守外包络检查。USB 焊盘和电池胶带属于表面展示，不参与装配碰撞；USB 十个焊盘另逐一做了金属接触检查。另检查 11.80 mm 焊耳包络、两个 90° 凹口及同心凸台间隙、孔位、顶柱连接、中心键 15 个按压位置，以及参考梯形宽度。所有打印件均为封闭、正体积、单体连通网格。

[导出检查](review/export-checks.json) 重新读取全部 11 个 STL 和两份 3MF，确认实体有效、包络对应、3MF 单位为 mm，板框包含六个闭合轮廓。USB-C 的 STL 包含整只母座；RGB 在 3MF 中使用封闭外包络，原始细节网格只用于 HTML 预览。

[浏览器报告](review/browser-checks.json) 验证器件来源与原始三角面数量、六个端子及四个固定脚、PCB 装配视图、离线加载、无脚本错误、梯形端面、顶角凹口、下盖配合、LED 位置及三点固定坐标、正面/背面/特写、爆炸、透明、图层、剖切、未缩放原型对照、两段运动、STL 下载及移动屏幕横向排版。截图保存在 `review`。

本版完成机械几何评审，尚未实物试装。没有进行结构强度、疲劳、打印收缩、LED 混色、按键材料变形或电气/RF 验证。
