建模过程只平移、旋转下载网格，没有拉伸或重绘。USB 源模型 Y=-3.4 是插口前端，Z=-0.1 是最低焊脚；将焊脚底面放在 PCB 顶面。TS-1101-C-W 源模型的最低焊脚为 Z=-0.593335，安放后总高约 2.497716 mm，与标称 2.5 mm 对应。变换和源包络均写入 `output/review/geometry-checks.json`。

USB 库模型的焊耳总宽为 11.44 mm，而随附 HX 厂家图纸为 11.80 mm。预览保留下载网格，额外以放宽至 11.80 mm 的包络检查 PCB 和壳体；焊盘按同物料的库封装展示。全部 10 个焊盘距板边至少约 0.407 mm。库模型及库封装不能代替实物复核或正式 PCB 封装审核。

源 USB 和普通开关包含多个封闭实体；碰撞检查对每个器件内部实体先求并集，避免内部重叠被重复计数。RGB 源网格存在非封闭和重合面，因此只在预览中保留原网格，几何检查、剖面及 3MF 用保守外包络。打印件均单独检查为封闭、连通实体。`usb_shell.stl` 保留旧文件名，但现在包含整只 6Pin 母座的实体并集。

正常重建完全离线使用这些已归档的模型。校验或恢复缺失文件：

```sh
uv run python scripts/fetch_component_models.py
```

脚本只恢复缺失文件；下载内容必须与锁定的 SHA-256 一致。如果上游改变文件，脚本报错，不会静默更新模型。
